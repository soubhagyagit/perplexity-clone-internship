# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within NexusAI, please do not open a public GitHub issue. Instead, report security concerns directly to the project maintainers via private security disclosure or email.

All security vulnerabilities will be promptly addressed and patched.
